# OpenDataLogger — primeira publicação do código-fonte

Base técnica: **v1.0.2**; preparação GitHub não altera o algoritmo de aquisição nem o firmware.

- O sketch está na raiz do repositório e pressupõe repositório/pasta com nome `OpenDataLogger`.
- `arduino_secrets.h` não é distribuído; criar a partir de `.example`.
- Adicionados MIT, SECURITY, CONTRIBUTING, plano de ensaios e GitHub Actions.
- A compilação real do núcleo Renesas e o armazenamento microSD exigem validação adicional.
- O nome 1.0.2 indica o conjunto de funcionalidades, não uma certificação de exactidão metrológica.
