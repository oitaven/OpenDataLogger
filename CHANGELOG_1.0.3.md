# OpenDataLogger v1.0.3 (experimental)

- Separador **Sistema**: capacidade do histórico em RAM, número de registos calculado conforme os canais físicos activos e duração máxima estimada para o intervalo de aquisição.
- Actualização dos indicadores após sair de **Canais**, alterar o intervalo e quando chegam novos dados, sem consultas HTTP adicionais.
- Crédito do projecto: **Made by Ricardo Oitavén & Eyla IA**.
- Matriz LED: mantida sem alterações; para a sinusoide de demonstração de 9,5 s recomenda-se janela de 10 s.
- Aquisição prioritária GPT, registo de eventos digitais, servidor Web e suporte opcional a SD: sem alterações nesta revisão.

Esta é uma versão experimental. A compilação Arduino Renesas e a validação física devem ser confirmadas através do GitHub Actions e do Arduino IDE.
