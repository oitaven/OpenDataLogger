# Contribuir

Contribuições são bem-vindas. Antes de abrir uma alteração:

1. Criar um issue com o comportamento esperado e a versão de Arduino IDE/UNO R4 Boards.
2. Testar o sketch no Arduino IDE com a placa **UNO R4 WiFi** e, quando disponível, verificar a acção de compilação no GitHub.
3. Não incluir nunca `arduino_secrets.h`, credenciais, registos pessoais nem capturas com dados privados.
4. Preservar a prioridade das interrupções de aquisição e não executar Wi-Fi, SD ou cálculos pesados nas ISR.
5. Descrever diferenças entre **resultado testado na placa** e simulação/navegador.
6. Usar canais genéricos em exemplos; instalações específicas devem ficar apenas como aplicações demonstrativas.

Idiomas preferenciais para documentação: português europeu e inglês (EN-GB), conforme colaboração futura.
